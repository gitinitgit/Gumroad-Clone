# Full-Stack Next.js — Build & Deploy

Master full-stack web development with **Next.js 14**, TypeScript, Prisma, and Tailwind CSS. Build and deploy 3 complete production apps from scratch.

## What You'll Build

### Project 1: SaaS Dashboard
- Authentication with NextAuth.js
- Role-based access control
- Real-time data with Server-Sent Events
- Stripe subscription billing

### Project 2: E-Commerce Store
- Product catalog with ISR
- Shopping cart with Zustand
- Razorpay/Stripe checkout
- Order management dashboard

### Project 3: Social Platform
- User profiles and feeds
- Real-time messaging
- Image uploads with Cloudinary
- Full-text search with Meilisearch

## Tech Stack Covered

- **Next.js 14** — App Router, Server Actions, RSC
- **TypeScript** — End-to-end type safety
- **Prisma** — Database ORM with PostgreSQL
- **Tailwind CSS** — Utility-first styling
- **NextAuth.js** — Authentication
- **Vercel** — Deployment & CI/CD
- **Docker** — Containerization
